UltimateChristmas - custom boss models
======================================

The plugin can render animated Blockbench boss models THREE ways:

  display       our own renderer - NO third-party plugin. Plays the model's
                animations (idle/walk/run automatically, attack/laugh/etc. on
                events). This is the default for the Grinch.
  modelengine   render through ModelEngine
  bettermodel   render through BetterModel

Pick one per boss with `model.provider` in modules/bosses.yml.

grinch.bbmodel is a rigged, animated model (bones + idle/walk/attack). It is
generated by tools/generate_grinch_model.py and is self-contained.

------------------------------------------------------------------------------
USING THE BUILT-IN "display" PROVIDER  (no extra plugin)
------------------------------------------------------------------------------
The display provider draws the model with vanilla display entities, but players
must have a RESOURCE PACK for the model's shape to show. The pack is built for
you and lives at:

    plugins/UltimateChristmas/pack/UltimateChristmas-Models.zip

1. Host that zip anywhere players can download it over http(s) (Dropbox direct
   link, a GitHub release asset, your own web server, a pack-hosting service...).
2. In config.yml set:
       resource-pack:
         url: "https://your-host/UltimateChristmas-Models.zip"
         required: false
   The plugin sends it on join with the correct hash. (Or distribute the pack
   any other way you already use - server.properties, a pack merger, etc.)
3. In modules/bosses.yml the Grinch already uses:
       model:
         provider: display
         id: grinch
4. Summon it from the control center:  /christmas boss

If a player does NOT have the pack, the boss shows as an invisible mob with a
name tag. Set provider: none on that boss to fall back to the vanilla mob.

Tuning: if the model floats, sinks, is too big or faces the wrong way, adjust
model.scale, model.offset-y and model.yaw-offset in bosses.yml, then
/christmas module reload bosses. (These exist because exact placement depends on
the model and can only be eyeballed in-game.)

------------------------------------------------------------------------------
ADDING OR EDITING MODELS
------------------------------------------------------------------------------
1. Make/edit the model in Blockbench (https://www.blockbench.net) as a "free"
   model, with bones (groups) and animations. Save it as a .bbmodel into
   src/main/resources/models/ (dev) or share it with us.
2. Compile it:  python tools/generate_resourcepack.py
   This (re)builds pack/UltimateChristmas-Models.zip AND the runtime rigs in
   src/main/resources/rigs/<id>.json, reading WHATEVER bones and animations the
   model has - any clip names work (idle, walk, run, laugh, steal, celebrate...).
3. Rebuild the jar (mvn package) or drop the compiled rigs/<id>.json and the
   updated pack into plugins/UltimateChristmas/ and reload.
4. Point a boss at it in bosses.yml with model.id and map its clips under
   model.animations / model.ability-animations.

------------------------------------------------------------------------------
USING ModelEngine or BetterModel instead
------------------------------------------------------------------------------
Put grinch.bbmodel in that plugin's model folder, register it, set
model.provider to modelengine or bettermodel, and reload. Those plugins do
their own resource pack and support richer animation blending.
